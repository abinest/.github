### Why abinest

- **Project-first.** Work happens inside a project. Only its members see the content, and people join through a time-limited link.
- **Rooms.** Announcement rooms with threads, chat rooms, and private and group conversations.
- **Notifications and search.** A live inbox with optional email, and one search across people, messages, rooms and files.
- **Extensible.** Plugins add routes, slash commands and panel UI. Releases are installed from a registry.
- **Yours.** You host it, so you decide where the data lives. Apache-2.0.
